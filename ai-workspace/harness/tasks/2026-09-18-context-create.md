# 任务：从目录树确定位置并创建资料

## 目标与边界

- 任务类型：workspace 模板交互优化。
- 每个资料目录、文档右侧提供悬停显示的“+”，支持键盘和触屏。
- 目录创建子项；文档创建同级项；顶部入口创建根目录项。
- 明确区分文档与目录，创建面板显示位置，授权后保留位置。
- 成功后展开目标目录，新文档直接打开；空目录可继续添加资料。
- 保留已有品牌、授权服务、侧栏调整及用户本地配置修改；不提交、不推送。
