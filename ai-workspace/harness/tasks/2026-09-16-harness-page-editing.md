# 页面维护 workspace harness

状态：已完成，2026-09-16。

## 目标

产品经理等角色从页面维护工程自带的 harness，无需修改前端组件代码。

## 交付

- 空间配置下新增 Harness 管理，配置中心提供直接入口。
- Agent 工作规则和协作说明支持文字编辑与 Markdown 预览。
- 七个角色技能支持正文编辑，自动保留 YAML 元信息。
- 角色名称、职责和目录范围支持表单维护，可选高级 JSON。
- 保存到连接工程的标准规则文件；缺失时使用模板创建。团队规则可提交，个人路径配置继续忽略。
- 固定管理入口不依赖连接工程的文章，旧工程或空内容工程仍可使用。
- 实际工程规则优先，缺失文件明确显示模板。

## 验证

npm run check 通过：9 个脚本测试、Harness 文件读写与边界检查、21 篇文档检查、类型检查和构建。

Harness 检查覆盖默认模板、文件白名单、目录范围、技能元信息、文件创建、外部修改冲突、角色修改后实时刷新、损坏 JSON 可读取修复、跨工程保存保护，以及旧工程管理入口保留。

独立审查指出的旧规则展示与旧工程入口消失问题已修复。浏览器工具此前无法启动，本轮未完成真实浏览器目视和授权保存实测。

## 边界

当前通过浏览器授权文件夹写回工程，未引入本地后端服务。没有将模板或业务源码作为可编辑规则暴露。保存不会自动提交或发布，运行中的 Agent 需要重新读取新规则。
