# 任务：自定义模型供应商管理（F1-3）

## 目标与边界

- 预期结果：VoltMind 不再写死 DeepSeek 模型列表，用户可在设置页自主配置模型供应商（名称 / Base URL / API Key / 多个模型），对话页的模型选择器动态展示已配置模型，切换后请求使用对应模型。
- 任务类型：关联业务工程（前端 + Python 后端同时改动）。
- 关联工程 ID：未登记，`code/projects.local.json` 的 `projects` 仍为空数组。
- 范围和完成标准：支持新增、编辑、删除供应商；每个供应商可挂多个模型并自定义模型 ID 与显示名称；初期只支持 OpenAI 兼容协议；保留既有 DeepSeek 配置的兼容性；安全上满足「密钥不写 localStorage、不回前端、服务端加密落盘、限制自定义 Base URL 防 SSRF、模型调用只允许已保存配置」。
- 明确不做：RAG、知识库、文档入库、向量检索、多轮记忆、SSE 流式输出、Java 后端、Vue Router 与状态管理库、模型连通性测试按钮、非 OpenAI 兼容协议。

发现并修复的两个缺陷：

1. **CORS 未放行 `PUT`/`DELETE`**：浏览器预检不通过，界面上的编辑与删除在真实浏览器里静默失败（用 HTTP 客户端测不出来）。已改为放行 `GET/POST/PUT/DELETE/OPTIONS` 并补用例。
2. **目录刷新覆盖用户选择**：进入对话页会刷新模型目录，原先「后端默认模型优先」的定位顺序会把用户刚选的模型顶回默认值。已改为「已选且仍可用 > 后端默认 > 列表首项」，补了回归断言。
