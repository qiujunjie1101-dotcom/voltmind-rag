# 任务：本地编辑支持服务授权连接

## 目标与边界

- 用户反馈“本地编辑”的文件夹按钮在内置浏览器仍被禁用。
- 任务类型：workspace 模板修复。
- 在本地开发服务增加文档、目录、媒体操作，用户明确授权后才连接；支持无需文件夹 API 的浏览器。
- 个人配置与资料编辑使用独立授权；本轮不扩展 Harness 管理权限，不访问业务工程。
- 保留已有品牌、配置授权及其他未提交工作。

## 交接

- 已完成。当前开发页面刷新后使用“本地编辑 → 授权连接当前空间 → 允许并连接”。
- 服务授权仅覆盖知识文档、目录和媒体，与个人配置授权分离；刷新页面或服务重启后重新授权。
- 当前服务只连接运行中的 workspace；原生浏览器文件夹选择仍可连接其他 workspace。
- 未提交、未推送；写入验证均在临时副本进行，未改用户个人配置或真实资料正文。
