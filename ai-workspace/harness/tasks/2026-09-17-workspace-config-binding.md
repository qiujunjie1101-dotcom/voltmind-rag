# 任务：内置浏览器授权绑定与配置保存

## 目标与边界

- 预期结果：不支持文件夹 API 的浏览器，也可由用户授权绑定正在运行的 workspace，读取并保存本地配置。
- 任务类型：workspace 模板。
- 范围：开发服务固定配置文件、配置中心授权 UI、导入草稿保留、保存冲突校验。静态部署保留文件夹授权和导入下载。
- 本地配置服务不提供任意路径读写，不扩展到业务工程、文章或 harness 编辑。

## 上下文

- 用户明确要求可授权绑定空间并保存，不能仅提供禁用按钮。
- 现状：配置保存依赖 showDirectoryPicker，导入只修改草稿，连接会覆盖草稿。
- 已有修改：node_modules/.vite/deps/_metadata.json 为启动服务的缓存变更，保留不纳入成果。
