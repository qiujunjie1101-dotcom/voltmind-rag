## 当前正在建设

Ai Workspace 是项目知识管理基础模板，提供多层级 Markdown 导航、文档阅读、代码高亮、文章大纲、本地内容编辑和媒体管理，并通过项目引用与 Harness 组织研发协作。

## 核心流程

复制模板 → 初始化空间 → 配置个人角色与工程路径 → 维护需求和设计 → 在业务工程实施 → 保存验证证据与任务交接。

| 环节 | 本期范围 |
| --- | --- |
| 项目空间 | 独立工程、默认分类、稳定文档链接与可替换品牌 |
| 本地配置 | 工程 ID、名称、路径与多角色选择，支持导入、下载和授权保存 |
| 资料维护 | Markdown 阅读与本地编辑、媒体附件、保存冲突提示 |
| 协作约定 | Agent 入口、角色职责、模板、任务记录与跨角色交接 |
| 质量检查 | 配置、文档链接和构建检查；业务工程独立验证 |

本地开发服务的配置授权只允许读写当前空间的个人配置。文档与 Harness 保存仍需浏览器文件夹授权。角色目录限制是协作约定，不是账号权限系统。

## 暂缓讨论的能力

团队账号与在线权限、服务端文档存储、实时多人协同、跨项目聚合和大型全文搜索，需结合实际项目规模与维护成本评估。

## 下一次需要作出的决定

在新项目复制与首次配置过程中记录实际问题，优先减少人工替换遗漏、配置理解成本和交接信息缺失。验证结果必须带环境与证据，不能用范围说明代替验收。
