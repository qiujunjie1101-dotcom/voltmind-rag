## 一句话定位

多模态智能知识库系统，以 AI 应用开发为核心。

## 定位要点

| 维度 | 内容 |
| --- | --- |
| 系统形态 | 知识库系统 |
| 能力特征 | 多模态 |
| 建设主线 | AI 应用开发 |
| 技术形态 | Java 业务服务与 Python AI 服务分离，通过 HTTP 通信，见《[技术架构](../../03-技术空间/01-架构设计/02-技术架构.md)》 |
| 推进节奏 | 先完成基础 RAG，再逐步演进，见《[架构原则与演进](../../03-技术空间/01-架构设计/03-架构原则与演进.md)》 |

## 核心链路

RAG 是这个系统的能力主体，包含两条核心链路：文档入库、知识检索问答。两条链路的实现方案见技术空间《[技术架构](../../03-技术空间/01-架构设计/02-技术架构.md)》。

## 待明确

以下内容尚未确定，不影响当前推进，但会影响资料组织与验收标准：

- 主要使用者与典型使用场景
- 知识库要收录的资料类型、规模与来源
- 多模态能力的具体范围（文本之外要覆盖哪些模态）
- 成功的判据（检索质量、问答质量的衡量方式）
