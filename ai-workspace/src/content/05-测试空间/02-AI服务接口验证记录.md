服务以 `LLM_TIMEOUT_SECONDS=30` 启动在本机 8010 端口（8000 被一个旧版本实例占用，未干扰），脚本逐项发起真实 HTTP 请求。

### 界面流程验证（无头 Chrome + CDP）

用无头 Chrome 走真实浏览器流程，共 38 项，全部通过。关键结论：

| 检查 | 实际结果 |
| --- | --- |
| 模型选择器 | 按供应商分组渲染，默认选中后端返回的默认模型；无可用模型时提示去设置页 |
| 新增表单 | 名称 / Base URL / API Key 三项齐全，密钥输入框为 `password` 类型 |
| 密钥外泄面 | 页面 DOM 不含明文密钥；`localStorage`、`sessionStorage`、`cookie` 均无密钥（仅主题偏好 `vueuse-color-scheme`） |
| 编辑与删除 | PUT/DELETE 预检通过，编辑保存生效、两步确认删除生效 |
| 切换模型后提问 | 切到自定义模型后请求确实走该模型（不可达端点返回 502 并展示错误气泡） |
| 真实模型链路 | 切到自定义真实端点后界面端到端返回回答，回答标签标注「VoltMind · DeepSeek Chat（UI）」 |

本轮发现并修复两个缺陷：CORS 未放行 `PUT`/`DELETE`（浏览器静默失败，界面无法编辑或删除）；目录刷新会把用户已选的模型顶回后端默认值。
