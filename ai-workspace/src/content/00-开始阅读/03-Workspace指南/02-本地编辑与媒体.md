## 连接项目文件夹

通过 `npm run dev` 打开空间后，点击右上角 **本地编辑 → 授权连接当前空间**。核对面板中的 workspace 路径和读写范围，再点击 **允许并连接**。应用内浏览器无需提供文件夹选择接口，也能使用这条连接方式。

授权允许读取和保存 `src/content` 下的 Markdown、创建资料目录、保存目录顺序，以及保存插入的图片和视频到 `public/media`。个人配置与 Harness 规则不在文档编辑授权内。需要编辑另一个空间时，从目标 workspace 启动开发服务并打开其地址。

桌面 Chrome、Edge 等支持 File System Access API 的浏览器也可使用 **选择项目文件夹**，选择包含 `package.json` 和 `src/content` 的根目录并授予浏览器读写权限。静态部署只有这种直接文件夹连接方式。

## 创建目录和文档

在左侧目录树中找到目标位置，将鼠标移到该行，点击右侧 **+**。键盘聚焦时也会显示入口，触屏设备始终显示。

| 从哪里创建 | 操作 | 保存位置 |
| --- | --- | --- |
| 目录右侧 **+** | 新建文档 / 新建子目录 | 当前目录内部 |
| 文档右侧 **+** | 同级新建文档 / 同级新建目录 | 当前文档所在目录 |
| 顶部“文档”旁 **+** | 新建文档 / 新建子目录 | 知识库根目录 |

目录用于组织文档和子目录；文档用于记录 Markdown 正文，不能包含子项。创建面板会显示层级和完整保存位置，只需填写名称，无需在长列表里重新选择目录。未连接时先授权，所选位置会保留；目录已不存在时会提示重新选择，不会改存到根目录。

- 文档保存为 `src/content/所选目录/文档名.md`。
- 新目录会写入 `.gitkeep`，空目录也能被 Git 保留。
- 创建后自动展开对应层级；新文档保存后直接打开。可继续从空目录的 **+** 添加内容。
- 文件名用于本地路径；文档中的 `title` 控制显示标题，`slug` 控制访问链接。
- 同名文件与重复 slug 会阻止保存，不会静默覆盖现有文档。

## 目录树与更多操作

目录左侧的三角用于展开和收起，文档使用文件图标，长标题保持单行并可悬停查看全名。将鼠标移到某一行，右侧显示 **+** 和 **…**；键盘聚焦与触屏也能使用这两个入口。

- 文档的 **…**：编辑该文档、复制它的链接或相对路径，无需先打开文章。
- 目录的 **…**：复制相对路径、展开所有子目录或收起当前目录。
- 顶部“文档”的 **…**：展开或收起全部目录；左侧箭头可折叠整个列表。
- 打开菜单不会改变当前文章，也不会误触目录展开。按 `Esc` 关闭菜单并回到操作按钮。

## 拖拽调整顺序

按住目录或文档行，上下拖到同层目标的上方或下方，看到蓝色落点线后松开。文件夹与文档可以混排，文件夹的子项随其一起显示。拖动到列表边缘会自动滚动；按 `Esc` 或拖出目录区域可取消。

首次排序会显示目标空间与授权范围，确认后保存；已有内容编辑连接时直接保存。保存成功后位置立即更新，当前阅读文章保持不变。刷新、重新连接或重新构建后继续使用相同顺序，只有手动调整才会改变已有顺序。

手机与键盘可从该行的 **… → 上移 / 下移 / 置顶 / 置底** 完成同样操作。内置管理页面不参与排序。当前支持同级调整，不改变文件所在目录、文件名、slug 或正文链接。

顺序写入 `src/content/.navigation.json`，可随项目一起提交；设置过顺序的目录新增资料时，会放在已有条目后。保存失败保留原顺序并提示原因；遇到外部修改冲突，可点击“重新读取”，核对后再调整。

## 编辑与预览

点击文章信息行中的 **编辑**。编辑器提供 Markdown 源码、预览和双栏视图，文件开头的 YAML 信息也可直接修改。

使用 **保存到项目**，或按 `⌘S` / `Ctrl+S` 写入文件。文件已被其他编辑器修改时，会提示冲突并保留当前草稿；可以复制需要保留的内容，再重新读取和合并。

## 粘贴图片和视频

将剪贴板中的图片、视频文件粘贴到 Markdown 输入框，或使用“插入媒体”选择文件，也可以拖入文件。

剪贴板是否提供视频文件，取决于来源应用和浏览器。只有文字链接时，不会自动下载媒体；这种情况下请使用文件选择入口。

本地服务连接时，单个媒体最大 20 MiB，单次保存媒体总量最大 40 MiB。媒体先在草稿中预览，点击保存后才写入 `public/media`，文件名由 UUID 生成。取消编辑不会把草稿中的媒体写入项目，也不会修改原文件。

## 调整媒体尺寸

插入媒体后，在编辑器下方选择对应文件，设置宽度和可选高度，再点击“应用尺寸”。高度留空时保持原始比例；点击“自适应”可恢复默认尺寸。

尺寸保存在标准 Markdown 的标题字段中，例如：

```markdown
![流程截图](./media/唯一文件名.png "width=640")
![演示视频](./media/唯一文件名.webm "width=640 height=360")
```

知识库会把常见视频后缀渲染为带控制栏的视频，图片和视频都不会超出正文宽度。原始媒体保持不变，只调整展示尺寸。

## 保存与发布的区别

本地开发模式由当前 workspace 的本机服务执行已授权的文档与媒体保存；直接文件夹模式由浏览器写入所选目录。两种方式都不会将内容上传到远程站点。单篇 Markdown 在本地服务模式下最大 2 MiB。

本地服务授权可通过编辑器底部“解除连接”撤销；当前未保存草稿保留，重新授权后可继续。刷新页面或重启服务后需要重新授权。

本地保存完成后，知识库会重新读取文档。线上静态站点不会随之自动变化，需要重新构建并发布。使用直接文件夹模式时，浏览器会记住已选择的 workspace。权限有效时下次自动连接；权限过期时点击“连接已记住的项目”重新授权，无需重新选择。目录移动、更换浏览器或清除网站数据后可能需要重新选择。
