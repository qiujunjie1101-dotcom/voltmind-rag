## 实现范围

R1-2 在 `voltmind-server/` 增量实现 5 个知识库接口和 4 个文档接口。Controller 只处理 HTTP 与 DTO，Service 负责校验、事务和文件补偿，Mapper 继续使用 MyBatis-Plus `BaseMapper`。

未实现文档解析、Chunking、Embedding、Milvus、RAG、SSE、鉴权和前端改造。

## 关键决定

- API 不直接返回 MyBatis-Plus 实体。
- 知识库名称在 Service 去除首尾空格，最终唯一性由 MySQL 唯一约束保证。
- 文件扩展名和媒体类型使用白名单；客户端不能传服务端保存路径。
- 文件使用 UUID 和两位分片目录保存，避免同名覆盖。
- 上传数据库失败时同步补偿删除文件。
- 文件删除失败时保留数据库记录并返回明确错误。
- 删除知识库时显式删除文件和文档记录，外键保持 `RESTRICT`。

## 配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `FILE_STORAGE_ROOT` | `./data/uploads` | 本地文件根目录 |
| `MAX_FILE_SIZE_BYTES` | `20971520` | 业务校验上限，字节 |
| `MAX_FILE_SIZE` | `20MB` | Spring multipart 请求上限 |
