## 架构原则

- Java 和 Python 采用独立服务，通过 HTTP 通信。
- Java 负责业务逻辑，Python 负责 AI 能力。
- RAG 包含文档入库和知识检索问答两条核心链路。
- 初期使用云端模型 API，不部署本地大模型。
- 不提前引入不必要的复杂架构。

## 演进路线

按顺序推进，前一步完成并验证后再进入下一步：

| 顺序 | 阶段 |
| --- | --- |
| 1 | 基础 RAG |
| 2 | 混合检索 |
| 3 | Reranker |
| 4 | 多模态 |
| 5 | RAG 评估 |

## 明确不做

- 初期不部署本地大模型，统一走云端模型 API。
- 不提前引入不必要的复杂架构。
